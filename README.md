# Svamdi Mic - download

Repository pubblico **solo per la distribuzione** dell'app Android Svamdi Mic.
Il codice sorgente non è qui.

- Pagina di installazione: https://fede-barba.github.io/svamdi-mic-releases/
- Ultima versione: 0.3.0 (build 8)
- APK: `svamdi-mic.apk` (asset dell'ultima release)

L'APK è firmato con la chiave release di SVAMDI: ogni aggiornamento si
installa sopra la versione precedente. Installazione fuori dal Play Store:
Android chiederà di consentire l'installazione da browser e Play Protect
potrebbe chiedere conferma.

Dopo l'installazione, apri l'app e inquadra il QR "Collega il telefono" dal
pannello **Compila** del desktop. Per funzionare, telefono e computer devono
essere sulla stessa rete Wi-Fi.
